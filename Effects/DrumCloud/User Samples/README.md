# User Samples — v0.26 groundwork

This dedicated folder is reserved for your own samples. Factory files remain
in Data/DrumCloud and are never renamed by the installer.

v0.26 keeps the existing /DrumCloud file slider for preset compatibility.
A separate User file selector and Factory/User tabs are not implemented yet.
Do not rely on recursive discovery of this folder by the native file slider.
For use today, copy a uniquely named WAV into Data/DrumCloud, reopen the effect,
and select it using Sample. Keep your master copy here if desired.
Use Detect Root, inspect the confidence, then explicitly Apply Root + Tune.
No filename-based factory root mapping is promised for user audio.

Full custom folder browsing is deferred to the GUI overhaul.
